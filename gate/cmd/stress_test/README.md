# 扫雷游戏压测机器人

一个专门用于扫雷游戏的压测工具，支持多机器人并发测试。

## 功能特性

- **多机器人并发**: 支持1-5000个机器人同时运行
- **随机行为**: 随机选择玩法1或2，随机下注金额
- **智能策略**: 随机决定是提现还是取消下注
- **实时统计**: 每10秒输出关键性能指标
- **优雅退出**: 支持Ctrl+C安全停止所有机器人
- **低日志输出**: 仅输出关键统计信息，避免日志刷屏

## 构建和运行

### 构建
```bash
./build.sh
```

### 运行示例
```bash
# 基础测试 - 10个机器人
./bin/stress_test

# 中等压测 - 100个机器人
./bin/stress_test -bots 100

# 高强度压测 - 500个机器人，20%取消下注
./bin/stress_test -bots 500 -cancel-ratio 0.2

# 自定义下注金额范围
./bin/stress_test -bots 50 -bet-min 5.0 -bet-max 50.0

# 查看所有参数
./bin/stress_test -help
```

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `-bots` | 10 | 机器人数量 (1-5000) |
| `-server` | ws://127.0.0.1:5600/ws | WebSocket服务器地址 |
| `-bet-min` | 10.0 | 最小下注金额 |
| `-bet-max` | 100.0 | 最大下注金额 |
| `-cancel-ratio` | 0.5 | 取消下注比例 (0.0-1.0) |

## 机器人行为

### 登录信息
- **用户名**: Ltest000001 - Ltest005000
- **Token**: abcabc
- **游戏类型**: mines_pro

### 行为策略
1. **登录后**: 等待游戏开始
2. **开始下注**: 随机延迟0-3秒后下注
3. **下注内容**: 随机选择玩法1或2，随机金额
4. **停止下注后**: 根据配置比例决定提现或取消下注
5. **心跳维持**: 每10秒发送一次心跳包

## 统计输出

每10秒输出一次统计信息，包括：
- 总机器人数
- 登录成功/失败数
- 下注成功/失败数  
- 提现成功/失败数
- 取消下注成功/失败数
- 总错误数
- 各操作成功率

## 注意事项

1. **连接限制**: 机器人每50个批次会暂停1秒，避免瞬间大量连接
2. **内存占用**: 每个机器人约占用几KB内存，5000个机器人约需50MB
3. **网络带宽**: 根据服务器性能调整机器人数量
4. **优雅退出**: 使用Ctrl+C停止，程序会安全关闭所有连接

## 故障排除

- **连接失败**: 检查服务器地址和端口
- **登录失败**: 确认token配置正确
- **下注失败**: 检查游戏服务器状态
- **内存不足**: 减少机器人数量
